## 1. Overview

### 1.1 Purpose

This document maps the complete indicator framework used by the NBSAP Monitoring Dashboard, showing how Rwanda's 22 national targets, ~80 indicators, 7 reporting tools, and 13 automated metrics interconnect. It serves as the definitive reference for understanding what the dashboard measures, how data flows from field reports to national progress, and how the system aligns with the Kunming-Montreal Global Biodiversity Framework (KM-GBF).

### 1.2 Framework Structure

```
┌─────────────────────────────────────────────────┐
│           KM-GBF GLOBAL FRAMEWORK                │
│         23 Global Targets / 4 Goals              │
```

## 3. Indicator Tier Classification

The system follows the official KM-GBF three-tier indicator structure:

### 3.1 Tier Definitions

| Tier | Name | Purpose | Example |
|---|---|---|---|
| **Tier 1** | Headline Indicators | High-level, internationally comparable metrics required for CBD national reporting | % of national territory under protection |
| **Tier 2** | Component Indicators | Detailed implementation metrics for adaptive management | Number of hectares reforested per district |
| **Tier 3a** | Binary Indicators | Yes/No policy condition assessments | National ABS law enacted (Yes/No) |
| **Tier 3b** | Complementary Indicators | Additional context metrics supporting analysis | Species occurrence count from GBIF |

### 3.2 Indicator Distribution

| Tier | Count | % of Total | Typical Data Source |
|---|---|---|---|
| Headline | ~22 | 28% | Aggregated from T01–T07 reports |
| Component | ~35 | 44% | Detailed field data from T02–T04 |
| Binary | ~10 | 13% | Policy assessment via T01 |
| Complementary | ~12 | 15% | GBIF, RBIS, analytical calculations |
| **Total** | **~79** | **100%** | |

### 4.1 Tool-to-Target Alignment

| Tool | Domain | Primary Targets Fed | Key Indicators Updated |
|---|---|---|---|
| **T01** | National Institutional Reporting | 14, 17, 18 | Policy integration %, biosafety score, subsidy reform value |
| **T02** | Ecosystem & Habitat Monitoring | 1, 2, 8, 11 | Spatial plan coverage, restoration hectares, NbS area |
| **T03** | Protected Area Management | 3, 4, 6 | PA coverage %, management effectiveness, illegal cases |
| **T04** | Human-Wildlife Conflict | 4, 5, 9 | HWC incident count, species conservation status, community benefits |
| **T05** | Finance & Resource Mobilisation | 18, 19 | Budget allocated, disbursed, finance mobilised |
| **T06** | Private Sector EIA Compliance | 7, 15 | EIA compliance rate, biodiversity risk disclosure |
| **T07** | Community Engagement | 9, 20, 22 | Community participants, traditional knowledge entries |

### 4.2 Data Flow: Report → Metric → Target Progress

```
Reporter submits T02 report
  │
  ├── form_data includes: forest_hectares = 150, wetland_hectares = 45
  │
  ├── Report enters verification queue (status: 'pending')
  │
  ├── Reviewer approves report (status: 'approved')
  │
  ├── Database trigger fires:
  │    ├── system_metrics['forest_restored_ha'] += 150
  │    ├── system_metrics['wetland_restored_ha'] += 45
  │    └── system_metrics updated_at = NOW()
  │
  ├── Weighted progress trigger fires:
  │    ├── Target 2 progress = f(T02_weight × T02_metric_value, ...)
  │    └── nbsap_targets[2].progress updated
  │
  └── WebSocket pushes update to all connected dashboards
```

## 5. Automated System Metrics

### 5.1 Metric Inventory

The system automatically computes 13 national-level metrics from approved report data:

| # | Metric | Unit | Source Tool | Target(s) Fed |
|---|---|---|---|---|
| 1 | Forest Area Restored | Hectares | T02 | 2, 8 |
| 2 | Wetland Area Restored | Hectares | T02 | 2, 11 |
| 3 | Protected Area Coverage | % | T03 | 3 |
| 4 | Average Management Effectiveness | Score (0–100) | T03 | 3 |
| 5 | Total Illegal Cases Reported | Count | T03 | 3, 5 |
| 6 | Total HWC Incidents | Count | T04 | 4 |
| 7 | Total Budget Allocated | RWF | T05 | 19 |
| 8 | Total Budget Disbursed | RWF | T05 | 19 |
| 9 | Budget Disbursement Rate | % | T05 (calculated) | 19 |
| 10 | EIA Compliance Rate | % | T06 | 7, 15 |
| 11 | Private Sector Restoration Commitments | Hectares | T06 | 7, 15 |
| 12 | Community Participants | Count | T07 | 22 |
| 13 | Traditional Knowledge Entries | Count | T07 | 22 |

### 5.2 Metric Computation Rules

| Rule | Description |
|---|---|
| **Summation** | Forest ha, wetland ha, illegal cases, HWC incidents, budget, participants, TK entries are summed across all approved reports |
| **Average** | Management effectiveness is averaged across all approved T03 reports |
| **Ratio** | Disbursement rate = (total disbursed / total allocated) × 100 |
| **Coverage** | PA coverage = sum of reported coverage from T03 reports |
| **Reversal** | When an approved report is deleted, its contribution is subtracted from affected metrics |

## 6. Progress Calculation System

### 6.1 Tool Weights

Each reporting tool has a configurable weight determining its contribution to target progress. Weights are stored in the `tool_weights` table and can be adjusted by REMA Administrators.

**Example Weight Configuration for Target 2 (Ecosystem Restoration):**

| Tool | Weight | Contribution |
|---|---|---|
| T02 (Ecosystem Monitoring) | 0.50 | Primary data source |
| T03 (Protected Areas) | 0.20 | Restoration within PAs |
| T07 (Community Engagement) | 0.15 | Community-led restoration |
| T01 (Institutional) | 0.10 | Policy support |
| T05 (Finance) | 0.05 | Financial support |
| **Total** | **1.00** | |

### 6.2 Progress Formula

```
Target Progress (%) = SUM( tool_weight[i] × tool_completion[i] )
                      for all tools linked to this target

Where:
  tool_completion[i] = (current_metric_value / target_metric_value) × 100
                       capped at 100%
```

### 6.3 Status Colour Coding

| Colour | Range | Label | Meaning |
|---|---|---|---|
| Green | >= 70% | On Track | Target likely to be met by 2030 |
| Amber | 40% – 69% | At Risk | Intervention may be needed |
| Red | < 40% | Behind | Urgent attention required |

## 10. CBD National Report Alignment

The indicator framework enables direct export for Rwanda's periodic National Reports to the CBD Secretariat:

| CBD Reporting Requirement | System Coverage | Export Format |
|---|---|---|
| **Progress toward national targets** | 22 targets with quantified progress | CSV, PDF, JSON |
| **Headline indicator values** | ~22 headline indicators with baselines and current values | CSV |
| **Status of biological diversity** | Species data via GBIF, habitat data via T02/T03 | PDF report |
| **Threats and drivers** | Pollution (T06), IAS (T03), HWC (T04), land use (T02) | CSV, PDF |
| **Implementation measures** | Institutional actions (T01), finance (T05), capacity (T07) | CSV, PDF |
| **Effectiveness of measures** | Management effectiveness (T03), compliance rates (T06) | CSV |
